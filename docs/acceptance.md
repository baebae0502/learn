# Acceptance 추적표 (AC01–AC20)

- 갱신: 2026-10-21(M2 Linux 증거와 M2 macOS 실행 run 39534378577 반영, 이어서 M2 최종 리뷰 수정 반영) · 기준: `docs/spec.html` 14절 · 최종 완료 판정은 P6에서 한다. R1 완료를 전체 완료로 보고하지 않는다.
- 상태 범례: `통과`(이번 세션 자동 검증) · `부분`(일부만 자동 검증) · `미착수`. 근거 열의 테스트는 모두 현재 저장소에 존재한다. 상태 판정은 Linux/Xvfb 자동 검증 기준이다.
- 검증(M0 시점): vitest 9개 파일 72개 테스트, Playwright E2E 6개(Linux) 통과. M2 시점(최종 리뷰 수정 후): vitest 30개 파일 267개 테스트 통과(`pnpm test`). E2E는 `tests/e2e/`에 22개가 정의돼 있고 그중 2개는 macOS 전용이다(⌘O 정확히 1회, 전체 화면 빠른 전환 경합 특성 테스트). Linux에서는 20개 통과·2개 건너뜀. M2 macOS 실행(run 39534378577)은 최종 리뷰 수정 전이라 그때 정의돼 있던 20개를 돌렸다. 수정에서 더한 E2E 2개(`position.spec.ts` "opening a PDF records openedAt even when the page never changes", `platform.spec.ts` "ui.windowState() answers the current fullscreen and focus state that main sees")는 macOS에서 아직 돌리지 않았다.
- **Mac 증거** 열: GitHub macOS 러너(M1 VM, `macos-15`/`macos-26`)에서 얻은 근거. 실행·수치는 [`mac-verification.md`](mac-verification.md). VM 값은 참고값이며 AC16 등 성능 판정은 기준 장비에서 한다. 기능 E2E는 run 39442173392(macOS 15)·39444862608(macOS 26)에서 6개 중 5개 통과(`first-session.spec.ts`가 전체 화면 해제 멈춤으로 시간 초과), 테스트 수정 후 run 39451895620(macOS 15)에서 6/6 통과 + darwin 전용 특성 테스트 1개 예상 실패.
