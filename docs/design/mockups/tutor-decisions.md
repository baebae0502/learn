# 튜터 목업 — 소유자가 정할 것 (명세 4절)

- 목업: `tutor.html`(쿼리는 파일 머리 주석). 렌더: `pnpm mockups:render -- --only tutor` → `docs/design/renders/`(커밋 안 함), 대조표 `docs/design/contact-sheet-tutor.jpg`.
- 모든 렌더는 1440×900 @2x, 레이아웃 B. 아래 기본값(★)은 디자이너 권장이고, 다른 안은 쿼리 하나로 바뀐다.

## 1. 튜터 모드 폭과 범위 (`?width=`)

| 안 | 렌더 |
|---|---|
| 340 | `tutor--5-width-340-light-B.png` |
| ★ 380 | `tutor--5-conversation-light-B.png` |
| 440 | `tutor--5-width-440-light-B.png` |

- 권장: **기본 380, 범위 320–560 유지.** 1440 창에서 사이드바 240 + 튜터 380이면 리더가 820이라 A4 쪽이 100%로 들어간다(440은 91%로 줄어든다). 340은 한 줄이 짧아 번호 목록과 인용 칩이 자주 줄을 바꾼다. 큰 화면에서 넓히는 사람을 위해 상한은 560으로 둔다.

## 2. 메시지 모양 (`?msg=`)

| 안 | 렌더 |
|---|---|
| ★ 문서식(왼쪽 정렬, 사용자 메시지만 옅은 면) | `tutor--5-conversation-light-B.png` |
| 말풍선(양쪽) | `tutor--5-msg-bubble-light-B.png` |

- 권장: **문서식.** 답은 긴 한국어 문단·번호 목록·인용 칩이라 380 폭에서는 말풍선의 안쪽 여백(폭의 약 14%)이 아깝다. 공부 노트처럼 읽히고, 사용자 메시지는 옅은 면으로 충분히 구별된다.

## 3. 인용 칩 표기 (`?cite=`)

| 안 | 렌더 |
|---|---|
| ★ "42쪽" | `tutor--6-citation-light-B.png` |
| "p. 42" | `tutor--6-cite-p-light-B.png` |
| 아이콘 + 숫자 | `tutor--6-cite-icon-light-B.png` |

- 권장: **"42쪽".** 앱의 단위 규칙(디자인 명세 9절 "68쪽")·도구 칩("41–42쪽 읽음")·쪽 입력과 같은 말이고, 시간 인용은 "18:20"으로 자연스럽게 짝이 된다. "p."는 한국어 UI 안의 영어 약자이고, 12px 아이콘은 쪽과 시간을 아이콘으로만 가르게 해 읽기 부담이 크다.

## 4. 동의 화면의 자리 (`?consent=`)

| 안 | 렌더 |
|---|---|
| ★ 튜터 패널 안의 카드 | `tutor--2-consent-light-B.png`, `tutor--2-consent-dark-B.png` |
| 메인 창의 시트 | `tutor--2-consent-sheet-light-B.png` |

- 권장: **패널 안의 카드.** 튜터가 생길 바로 그 자리에서 묻고, 동의 전에도 리더는 그대로 쓸 수 있다(축 A — 자료는 AI 없이 완결). "나중에"를 누르면 같은 자리가 "튜터가 꺼져 있습니다 · 튜터 켜기…"로 남는다(시트 렌더의 패널). 시트는 더 무겁게 보이지만, 급하지 않은 선택에 창 전체를 막는다. 내용은 두 안이 같다.

## 5. 세션 목록의 자리 (`?sessions=`)

| 안 | 렌더 |
|---|---|
| ★ 왼쪽 사이드바 | `tutor--9-sessions-light-B.png`(리더: 넷째 세그먼트 "세션" — 이 자료의 세션, 제자리 이름 바꾸기·삭제), `tutor--library-light-B.png`(라이브러리: "세션" 묶음 — 자료별·최근) |
| 튜터 패널 머리의 목록 단추 | `tutor--9-sessions-panel-light-B.png` |

- 권장: **왼쪽 사이드바.** 디자인 명세 2.5와 Codex 스레드 목록의 자리이고, 튜터 패널은 대화 하나에 집중한다. 세션이 자료 아래 묶여 축 B(세션 → 자료)가 화면에 보인다. 비용: 리더 세그먼트가 넷이 되고, 다른 자료의 세션은 라이브러리 탭에서 찾는다. 패널 안은 대화에서 한 번에 열리지만 대화를 가리고 탐색 자리가 둘이 된다.

## 그 밖에 정할 것 (목업이 가정한 값)

- 모드 단축키(가안): 정보 ⌥⌘1 · 튜터 ⌥⌘2(Xcode 인스펙터 관례, 지금 키 맵과 충돌 없음). ⌥⌘I는 오른쪽 슬롯 보기/가리기로 두고 이름은 모드를 따른다("튜터 가리기").
- 자동 접힘 문턱: 리더 도구 막대가 한 줄에 들어가려면 약 660이 필요해, 리더에서는 창이 약 1280보다 좁으면 튜터가 먼저 접힌다. 좁은 창에서 튜터를 펼치면 사이드바가 접힌다(`tutor--10-narrow-*`).
- 실패한 요청: 답이 오기 전에 실패하면 질문이 입력창으로 돌아가고(오프라인·로그인 만료), 답하는 도중 실패하면 끊긴 답을 남기고 "다시 보내기"로 처음부터 묻는다(`tutor--8-*`). 자동 재전송은 없다.
