- 상태: **소유자 검토 대기** (2026-10-20) · 대상: M3–M9 구현
- 함께 볼 것: 목업 `docs/design/mockups/`(브라우저로 `index.html`), 대조표 `docs/design/contact-sheet-base.jpg`·`contact-sheet-variants.jpg`, 토큰 `apps/desktop/src/renderer/src/design/tokens.ts`, 비평 기준 `docs/design/review-rubric.md`, 참고 `docs/design/references.md`, ADR-0004(UI 스택)·ADR-0005(명령·메뉴·단축키)

## 1. 원칙

1. **절제** — 크롬은 중립 회색, 강조색은 하나(틸). 관심을 얻지 못한 요소는 경쟁하지 않는다. 그라데이션·빛 번짐·장식 그림자는 쓰지 않는다(드롭 오버레이의 흐림처럼 층을 구분하는 기능적 효과만 허용).
2. **내용 우선** — 자료(표의 제목, PDF 쪽, 영상)가 화면에서 가장 크고 밝다. 크롬은 내용보다 조용하다.
3. **키보드 우선** — 모든 명령은 단일 명령 레지스트리(ADR-0005)에 있고 메뉴·팔레트(⌘K)·단축키·컨텍스트 메뉴로 닿는다. 포커스는 항상 보인다.
4. **Mac 네이티브** — 숨긴 제목 막대 + 신호등, 52px 도구 막대, 사이드바 비브런시, 13px 본문, 네이티브 메뉴·컨텍스트 메뉴, `⌘` 기호 표기, 시스템 다크 모드.
5. **가짜 금지** — 동작하지 않는 컨트롤은 그리지 않는다. 목업은 목표 화면이지만 각 요소가 동작하는 마일스톤을 10절 카탈로그에 적는다(목업 `?ms=1`이 같은 표시를 화면에 띄운다).
6. **상태 기억** — 패널 폭·접힘, 열 구성·정렬, 밀도, 테마, 마지막 탭, 읽기 위치(쪽·시간)를 기억한다. 재시작하면 그대로 돌아온다.

## 2. 창과 패널 격자

### 2.1 공통
- 창: 기본 1440×900, 최소 960×600(`tokens.layout.windowMin*`). `titleBarStyle: 'hidden'`, `trafficLightPosition: {x: 18, y: 18}`(M3에서 macOS 러너로 확인), `vibrancy: 'sidebar'`. Linux/Windows는 `titleBarOverlay`(색은 `tokens.generated.ts`).
- 신호등: 12px 원 3개, 간격 8, 묶음 원점 (18, 20)에 그려 52px 막대 세로 가운데. 왼쪽 **84px**(`--traffic-light-inset`)은 신호등 전용이다. 신호등은 네이티브이므로 웹 내용(스크림, 드롭 오버레이)이 덮거나 흐리게 할 수 없다.
- 도구 막대 52, 창 머리 아래 패널 머리 44, 표 머리 28, 컨트롤 28(작게 22·24, 크게 32), 아이콘 히트 영역 28.
- 패널 폭(px, 드래그로 조절·기억): 사이드바 **240** (180–360), 항목 패널 **320** (260–480), 대본 패널 320. 창이 960에 가까워지면 항목 패널 → 사이드바 순으로 자동 접힌다(접힘 상태도 기억).
- 패널 경계는 1px `--separator`. 경계 위 ±4px가 크기 조절 핸들(커서만 바뀌고 선은 그대로).

### 2.2 레이아웃 A — Zotero식
```
┌──────────────────────────────────────────────────────────────┐
│● ● ●  [▯] [라이브러리][PDF 탭 ×][영상 탭]      [검색 및 명령 ⌘K]│ 52  --bg-window, 아래 구분선
├──────────┬──────────────────────────────┬────────────────────┤
│ 사이드바  │ 패널 머리 44                    │ 항목 패널           │
│ 240      │ 표 / 리더                       │ 320                │
└──────────┴──────────────────────────────┴────────────────────┘
```
- 제목 막대가 창 전체 폭. 84px 다음에 사이드바 토글(28), 8 띄우고 탭.
- 탭: 높이 28, 반경 6, 최대 240·최소 120, 간격 4. 활성 탭은 `--bg-control` + `--shadow-e0`, 비활성은 투명·`--text-secondary`, 비활성 탭 사이에 16px 높이 구분선. 닫기(18) 버튼은 활성·호버 탭에만. 라이브러리 탭은 닫을 수 없다(닫기 없음).
- 오른쪽 끝(12 띄움): 팔레트 실행기(필드 모양, 232×28, `⌘K` 키캡).

### 2.3 레이아웃 B — Codex / macOS 11+식
```
┌──────────┬───────────────────────────────────────────────────┐
│● ● ●  [▯]│ [라이브러리][PDF 탭 ×][영상 탭]                      │ 52
│[검색 ⌘K]  ├──────────────────────────────┬────────────────────┤
│ 사이드바  │ 패널 머리 44                    │ 항목 패널 320       │
│ 전체 높이 │ 표 / 리더                       │                    │
└──────────┴──────────────────────────────┴────────────────────┘
```
- 사이드바가 창 높이 전체. 위 52px에 신호등(왼쪽)과 사이드바 토글(오른쪽, 12 띄움). 그 아래 팔레트 실행기(사이드바 폭 − 24).
- 탭 막대는 내용 열 위 52px(`--bg-window`), 12 띄우고 시작.
- **사이드바를 접으면** 제목 막대가 84px 인셋과 사이드바 토글을 넘겨받는다(A와 같은 머리). 목업 `dialogs.html?scene=codec`.
- 사이드바 내용은 탭의 탐색기다: 라이브러리 탭 = 컬렉션·태그, PDF 탭 = 썸네일/목차/필기, 영상 탭 = 대본/시간 메모(폭 320). A에서는 같은 탐색기가 제목 막대 아래 왼쪽 패널에 들어간다. **오른쪽은 항목 정보(라이브러리)와 장차 튜터(P3) 자리**라 리더의 탐색기는 항상 왼쪽이다.

### 2.4 패널 머리(44)
- 왼쪽 16, 오른쪽 12. 제목 `--type-title3`(15/20 600) + 개수 `--type-footnote` `--text-tertiary` (간격 8).
- 오른쪽: 주요 동작(보조 버튼), 검색 필드(240), 패널 토글(아이콘 버튼, 켜짐은 `--fill-pressed`).
- 빈 라이브러리에서는 검색 필드와 항목 패널 토글을 그리지 않는다(동작할 대상이 없다).

## 3. 토큰

원본은 `tokens.ts`, 생성물은 `tokens.css`(CSS 변수)·`tokens.generated.ts`(main용 hex). `pnpm tokens`로 생성, `pnpm tokens:check`와 `tokens.test.ts`가 최신 여부를 확인한다. 화면 코드에서 색·간격·반경·글자 크기를 직접 쓰지 않는다. 목업에서 토큰이 아닌 값은 `/* local */` 주석으로 표시했다(신호등 색, 메뉴 내부 여백 5, 자막 크기 등).

### 3.1 색 (OKLCH, `light-dark()`)
- 중립: hue 250, chroma ≤ 0.01. 라이트에서는 내용(흰색)이 크롬보다 밝고, **다크에서는 내용이 크롬보다 어둡다**(macOS·Xcode·Finder와 같은 방향). 떠 있는 면은 다크에서 더 밝다(테스트로 고정).

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--bg-window` | 97.6% | 26.5% | 제목 막대·도구 막대·설정 시트 본문 |
| `--bg-sidebar` | 95.6% | 24.5% | 사이드바(비브런시의 불투명 대체값) |
| `--bg-content` | 100% | 21.5% | 표·항목 패널·리더 도구 막대 |
| `--bg-content-alt` | 98.4% | 22.8% | 표 줄무늬 |
| `--bg-raised` | 100% | 30% | 메뉴·팝오버·대화상자·토스트 |
| `--bg-sunken` | 93.2% | 17.5% | PDF 쪽 뒤 바탕 |
| `--fill-hover` / `--fill-pressed` / `--fill-selected` | 검정 5/9/9% | 흰색 6/10/11% | 모든 면 위 상태(반투명이라 면을 가리지 않음) |
| `--separator` / `--border` / `--border-strong` | 89.5% / 86% / 60% | 33% / 흰 12% / 62% | 구분선 / 컨트롤 테두리 / 3:1 경계 |
| `--text-primary` / `-secondary` / `-tertiary` | 23 / 46 / 60% | 94 / 76.5 / 58% | 본문 / 보조·아이콘 / 자리표시·개수 |
| `--accent` | `oklch(53% .088 190)` | `oklch(50% .084 190)` | 포커스된 선택 행, 기본 버튼 |
| `--accent-text` | 49% | 78% | 링크·사이드바 아이콘·강조 글자 |
| `--focus` | 57% | 72% | 포커스 링 |
| `--danger/-warning/-success`(+`-text`, `-soft`) | | | 의미색. 글자는 `-text`만 쓴다. |

- 강조색은 Linear식 base/accent/contrast: `accent`(채움) ↔ `textOnAccent`(흰 글자, 4.5:1 이상) ↔ `accentText`(면 위 글자, 4.5:1 이상). 다크의 채움은 라이트보다 어둡다(흰 글자 대비 때문). 모든 값은 sRGB 색역 안(생성기가 확인).
- **선택 규칙**: 키보드 포커스가 있는 목록의 선택 = `--accent` 채움 + 흰 글자(행 안 보조 글자·아이콘·진행 막대도 흰색). 포커스가 없는 목록의 선택 = `--fill-selected` 중립. 한 화면에 강조 채움 선택은 하나뿐이다.
- 태그·필기 8색(Zotero와 같은 순서·값, 두 테마 동일): 1 노랑 `#ffd400` · 2 빨강 `#ff6666` · 3 초록 `#5fb236` · 4 파랑 `#2ea8e5` · 5 보라 `#a28ae5` · 6 자홍 `#e56eee` · 7 주황 `#f19837` · 8 회색 `#aaaaaa`. 색 점 8px + 0.5px 안쪽 테두리. 선택 행 위에서는 흰 1px 고리.
- 찾기 일치는 **틸**(`--find-match`, 현재 일치는 `--find-match-current` + 1.5px 강조 테두리). 노란 하이라이트 필기와 절대 헷갈리지 않게 하기 위해서다.
- 쪽 테마: 원본(흰색), 세피아, 어둡게. 기본값은 "앱 테마 따르기"(다크 앱 → 어두운 쪽). 하이라이트는 밝은 쪽에서 `multiply` 40%, 어두운 쪽에서 `normal` 32%. 그림은 반전하지 않는다.
- `prefers-contrast: more`: 구분선·테두리 3:1 이상, 보조·3차 글자 진하게, 선택 채움 진하게(테스트 포함).

### 3.2 간격·반경·그림자·밀도
- 4px 격자: `--space-2/4/6/8/12/16/20/24/32/40/48`(이름이 곧 px). 2와 6은 아이콘-글자 간격 같은 반 단계에만.
- 반경: xs 3(키캡) · sm 4(칩 안 버튼, 작은 컨트롤) · md 6(버튼·필드·행·탭) · lg 8(메뉴·카드·토스트) · xl 12(대화상자·시트) · pill.
- 그림자: e0(활성 탭·세그먼트), e1(메뉴·팝오버·찾기 막대·토스트), e2(대화상자·시트), page(PDF 쪽). 모든 그림자는 0.5px 고리 + (다크) 위쪽 0.5px 안쪽 하이라이트 + 부드러운 그림자의 같은 구조라 `light-dark()` 하나로 테마가 바뀐다.
- 밀도(행 높이): 촘촘하게 24 · **보통 28** · 여유 있게 32. 사이드바 행·표 행·목차 행이 함께 바뀐다(`--row-height`).

- 글꼴: `--font-system` = `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Pretendard Variable", system-ui, sans-serif`(Mac은 시스템, Linux는 번들한 Pretendard). `?font=pretendard`/`data-font="pretendard"`면 Pretendard 우선.
- 한국어: 전역 `word-break: keep-all; overflow-wrap: anywhere; line-break: strict`. 문단은 `text-wrap: pretty`(한 단어 마지막 줄 방지), 짧은 제목은 `text-wrap: balance`. 숫자와 붙는 단위·고유명은 줄바꿈하지 않는 공백(예: `G 단백질`).
- 한글 UI에 700을 쓰지 않는다(600이 최대, 토큰 테스트). 자료 본문(PDF 쪽 안)은 자료의 글꼴이므로 예외.
- 숫자 열·시간·쪽·개수는 `font-variant-numeric: tabular-nums`(`.num`).
- 말줄임: 한 줄 셀은 `text-overflow: ellipsis`, 전체 텍스트는 툴팁(`title`)과 항목 패널에서 보인다. 가운데 생략은 쓰지 않는다(경로는 툴팁).

## 5. 아이콘
- lucide(ISC), **16px, stroke 1.5**(24 격자 기준 → 16px에서 1px 선), `currentColor`, 히트 영역 28. 작은 아이콘 14(필드 안), 펼침 화살표 12(stroke 2), 미디어 재생 20, 빈 상태 32(stroke 1.25).

## 7. 상호작용

### 7.1 선택 모델(표·트리·썸네일 공통)
- 클릭 = 하나 선택, ⇧클릭 = 범위, ⌘클릭 = 토글, ⌘A = 전체, 화살표 = 이동, ⇧화살표 = 확장, Home/End = 처음/끝.
- **오른쪽 클릭은 먼저 선택한다**: 선택되지 않은 행이면 그 행만 선택한 뒤 메뉴, 선택 안의 행이면 선택을 유지(Finder와 같다).
- 더블클릭·↩ = 열기(탭), ⌘↩ = 새 탭에서 열기(같은 자료 탭이 있으면 그 탭으로 이동).
- 컬렉션을 바꾸면 표 선택은 비우고 항목 패널은 "선택한 자료 없음" 빈 상태. 여러 개 선택이면 항목 패널은 "자료 3개" 요약(공통 태그·컬렉션만).
- 입력하며 행으로 건너뛰기(type-ahead)는 하지 않는다(한국어 IME와 충돌). 대신 ⌘F 빠른 검색.

### 7.2 드래그 앤 드롭
- **Finder → 창**: 창 전체 드롭 오버레이(목업 `library-empty.html?state=drop`). 기본은 사본 가져오기, ⌥를 누르고 있으면 외부 연결(오버레이의 두 카드가 즉시 전환). 파일 수·종류를 보여 주고, 지원하지 않는 파일은 놓은 뒤 결과 토스트에서 알린다.
- **Finder → 사이드바 컬렉션 행**: 그 컬렉션으로 가져오기(M5). 행이 드롭 대상 표시.
- **표 행 → 컬렉션**: 추가(자료는 여러 컬렉션에 속할 수 있다). ⌘ = 이동(현재 컬렉션에서 빼고 추가). 끌기 미리보기에 "자료 3개" 배지.
- **컬렉션 → 컬렉션**: 하위로 옮기기. 순환이 되는 대상은 드롭 표시를 하지 않는다.
- **태그 칩 → 표 행**: 태그 붙이기(M5). **탭 → 탭 줄**: 순서 바꾸기(M7).
- 끌기 중 esc = 취소. 드롭이 실패하면 원래 상태 그대로 + 오류 토스트.

### 7.3 컨텍스트 메뉴(네이티브 `Menu.popup`)
- 자료: 열기 ↩ · 새 탭에서 열기 ⌘↩ · — · Finder에서 보기 ⇧⌘R · 사본 내보내기… · — · 컬렉션에 추가 ▸ · 이 컬렉션에서 빼기 · 색 태그 ▸(1–8, 체크 표시) · — · 휴지통으로 이동 ⌘⌫. 파일 없음 자료는 맨 위에 "다시 연결…".
- 컬렉션: 새 하위 컬렉션 · 이름 바꾸기 · — · 이 컬렉션으로 가져오기… · — · 휴지통으로 이동.
- 태그: 이름 바꾸기… · 색 지정 ▸ · 색 해제 · — · 태그 삭제….
- 열 머리: 열 목록(체크) · — · 열 구성 되돌리기.
- 탭: 탭 닫기 ⌘W · 다른 탭 닫기 · — · 라이브러리에서 보기 · Finder에서 보기.
- 리더 본문 선택(M9): 하이라이트 ▸(8색) · 밑줄 · 노트 추가 · — · 복사 ⌘C.
- 표기: 대화상자가 열리는 항목은 "…", 하위 메뉴는 ▸, 단축키는 오른쪽, 위험 동작은 맨 아래 구분선 다음.

## 8. 모션·다크 모드·접근성

### 8.1 모션
- 지속 시간 100(호버·누름) / 160(팝오버·메뉴·토스트 등장) / 240(시트·드롭 오버레이). 곡선 `cubic-bezier(0.2, 0, 0, 1)`. 사라질 때는 0.75배.
- 이동 거리는 작게(팝오버 4px, 토스트 8px). 목록 갱신·정렬·필터에는 모션 없음. 진행 막대 폭 변화만 160.
- `prefers-reduced-motion: reduce`: 이동은 0(`--duration-move`), 불투명도 전환만 남긴다.

### 8.2 다크 모드
- 시스템 설정을 따른다(설정에서 라이트/다크 고정 가능, `nativeTheme.themeSource`). 첫 프레임 배경은 `tokens.generated.ts`의 `windowBackground`.
- 깊이는 그림자보다 **명도와 경계**: 내용 < 사이드바 < 크롬 < 떠 있는 면 순으로 밝아진다. 떠 있는 면에는 0.5px 바깥 고리와 위쪽 0.5px 안쪽 하이라이트.
- 강조 채움은 라이트보다 어둡게(흰 글자 대비), 강조 글자는 밝게. 의미색 글자도 밝은 변형(`-text`).
- 쪽은 기본으로 어둡게(설정 가능), 하이라이트는 불투명도를 낮춘다. 영상 바탕은 두 테마 모두 거의 검정.
- 라이트/다크 대등: 모든 목업을 두 테마로 렌더해 비교한다(대조표 열 1·2 vs 3·4).

### 8.3 접근성 목표(AC18)
- 대비: 본문·보조 글자 4.5:1 이상(모든 면·호버·비포커스 선택 위), 3차 글자·아이콘·포커스 링·강한 테두리 3:1 이상, 강조 채움 위 흰 글자 4.5:1 이상. `tokens.test.ts`가 두 테마와 고대비 모드에서 검사한다.
- 포커스 링이 항상 보인다. 포커스 순서는 화면 왼쪽→오른쪽, 위→아래. F6으로 패널 사이 이동(사이드바 → 표 → 항목 패널).
- 200% 확대에서 가로 스크롤 없이 쓸 수 있다(패널 자동 접힘).
- 키보드만으로: 가져오기 → 자료 열기 → 찾기 → 필기(M9) → 백업까지 완주(E2E로 검증).
- 히트 영역 28 이상(22 작은 버튼은 주변 4 이상 띄움).
- 의미를 색만으로 전하지 않는다(태그 점 옆 이름, 파일 없음은 아이콘+글자).
- VoiceOver: react-aria 시맨틱(grid, tree, tablist, dialog). 실기 확인은 Mac 실기 단계.

## 9. 문체
- 합니다체(결정 대기). 제목은 명사형 또는 완결문("이미 라이브러리에 있는 파일입니다"), 버튼은 짧은 동사형("건너뛰기", "새 자료로 추가", "다시 연결…").
- 오류 = **원인 + 다음 행동**: "필기를 저장하지 못했습니다. 디스크 공간이 부족합니다. 공간을 확보한 뒤 다시 시도하세요."
- 안심 문구는 사실일 때만: "원본 파일은 그대로 보관됩니다", "자동으로 지운 것은 없습니다".
- 숫자와 단위: "48개", "68쪽", "7 / 12", "2.4 GB". 날짜: 오늘·어제는 "오늘 오전 9:12", 그 밖은 "2026. 10. 12.". 영어 제목·저자는 원문 그대로.
- 내부 용어("P1 단계", "staging", "관리형") 대신 사용자 말("가져오는 도중 남은 임시 파일", "사본"). 경로·해시는 고정폭으로 보조 정보에만.
- 키 표기: 메뉴·툴팁은 "찾기 ⌘F", 본문은 키캡.

## 부록 A. 목업 사용법
- 쿼리: `theme=light|dark`, `layout=A|B`, `font=system|pretendard`, `density=compact|regular|comfortable`, `ms=1`.
- 렌더: `pnpm mockups:render` (Linux는 스스로 2880×1800 xvfb에서 실행). `--only <이름>`, `--base`, `--scale 1`. 결과 `docs/design/renders/*.png`와 `report.json`(실제 쓰인 글꼴), 대조표 2장.
- macOS: `tests/evidence/mockups.evidence.ts`(`@mockups`)가 같은 렌더를 macOS 러너에서 수행하고, 시스템 글꼴(SF/Apple SD Gothic Neo)이 실제로 쓰였는지 CDP로 확인한다.
- 아이콘을 추가하면 `node scripts/build-mockup-icons.mjs`(목업 스크립트에서 쓰는 lucide 이름을 모아 `icons.js` 생성).

## 부록 B. 라이선스
- Pretendard Variable 1.3.9 — SIL OFL 1.1, `design/fonts/Pretendard-LICENSE.txt` 동봉, npm `pretendard@1.3.9`(devDependency, 정확 고정).
